# PD5_paraules-matematiques
Fitxa interactiva de matemàtiques dissenyada per a connectar les expressions del llenguatge quotidià amb els percentatges i la probabilitat matemàtica.

**Característiques principals**

**Guia Visual de Referència:** Targetes interactives amb codis de colors, icones i indicadors de proporció visual (punts de 0 a 10).

**Línia Contínua de Percentatges (0% ➔ 100%):** Activitat dinàmica de 2 clics on l'alumnat situa les paraules sobre un eix visual de percentatges i probabilitat.

**Creació de Frases Quotidianes:** Espai adaptat amb idees visuals i selecció del terme matemàtic corresponent (Segur, Probable, Impossible).

**Problemes Pràctics:** Resolució de situacions reals amb opcions clares i retroalimentació immediata.

**Autocorrecció per Exercici:** Botons de verificació al final de cada secció per afavorir l'autonomia de l'estudiant.

**Enllaç per al Mestre / Mestra:** Generació d'un enllaç codificat que permet a l'estudiant enviar les respostes al docent directament a través de l'URL (sense necessitat de registre ni servidors).

**Reforç Positiu (Celebració):** Animació de confeti que es desbloca únicament en assolir el 100% del progrés.
